### 🛍️ Headless Shopify E-commerce Platform

A modern, headless commerce platform built with **Next.js, Express.js, Shopify GraphQL/REST APIs, and MySQL**.

- 🛒 Product listing and detail pages, collections, cart, checkout, and customer management.
- 🤖 AI shopping assistant for product discovery and personalized recommendations.
- 🪄 AI-powered virtual try-on using uploaded photos.
- 💳 Stripe payment integration and Shopify webhook workflows.
- 🌍 Multi-currency pricing, localized product experiences, and international shipping.
- 📊 Admin dashboard for orders, inventory, and analytics.

A fintech platform developed at Ethan.ai for wealth managers, banks, and high-net-worth individuals.

- 📈 Supports tracking and management of over **$100M in assets under platform (AUP)**.
- 🏛️ Built interactive financial interfaces for ICICI, Axis Bank, and CSBL.
- 🔄 Integrated automated data cleaning and real-time data updates.
- 💳 Implemented Razorpay payment workflows and webhook-driven transaction updates.
